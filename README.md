## ✨ Features

### 📄 Resume Builder

- **ATS-Optimized Templates** — Clean, professional templates designed to pass Applicant Tracking Systems
- **Live Preview** — See changes in real-time as you type
- **PDF Export** — Download publication-ready resumes instantly
- **Multiple Templates** — Choose from Modern, Classic, Minimal, Creative, Technical, and Academic styles

### 🔍 ATS Resume Checker

- **Instant Score** — Get a comprehensive ATS compatibility score (0-100)
- **Keyword Analysis** — Identify strong action verbs and missing industry keywords
- **Job Match** — Paste a job description and see how well your resume matches
- **Actionable Feedback** — Get specific suggestions to improve your resume

### 🔒 Privacy First

- **100% Client-Side** — All processing happens in your browser
- **No Account Required** — Start building immediately, no sign-up needed
- **Local Storage Only** — Your resume data stays on your device
- **No Server Upload** — We never see or store your personal information

### 📱 Progressive Web App (PWA)

- **Works Offline** — Install and use without internet connection
- **Mobile Friendly** — Fully responsive design for all devices
- **Fast & Lightweight** — Optimized for performance

## 📊 ATS Scoring Criteria

The ATS Checker analyzes resumes across four dimensions:

| Dimension       | Weight | What It Checks                               |
| --------------- | ------ | -------------------------------------------- |
| **Formatting**  | 25%    | File type, page length, complex elements     |
| **Keywords**    | 30%    | Action verbs, industry terms, skill mentions |
| **Structure**   | 25%    | Section headings, logical organization       |
| **Readability** | 20%    | Flesch-Kincaid score, sentence complexity    |

## ❓ FAQ

<details>
<summary><strong>Is ResuMeow really free?</strong></summary>
Yes! ResuMeow is completely free with no hidden costs, premium tiers, or paywalls.
</details>

<details>
<summary><strong>Is my data safe?</strong></summary>
Absolutely. All your resume data is stored locally in your browser's localStorage. We never send your data to any server.
</details>

<details>
<summary><strong>Can I use ResuMeow offline?</strong></summary>
Yes! ResuMeow is a PWA. After your first visit, you can install it and use it without internet.
</details>

<details>
<summary><strong>Why no photos on resumes?</strong></summary>
Photos can cause ATS parsing issues and may introduce unconscious bias. Most professional resume guidelines recommend against photos for US/UK job markets.
</details>
